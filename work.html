What we built for Pikenhot

Every system, in detail

Public Website
Fully custom-designed multi-page site. Gym info, sauna sessions, facilities, pricing, and contact. Animated, mobile-first, and fast.
Member Portal
Members log in to view membership status, manage subscriptions, see booking history, and update payment details — entirely self-service.
Payment Processing
Stripe integration for memberships, one-off sessions, and recurring billing. Full transaction history visible in the admin panel.
Staff Roster
Admin dashboard for managing staff shifts. Who's in, who's off — all in one place. No spreadsheets needed.
Opening Hours
Dynamic hours management. Update hours from the admin and they appear on the public site in real time.
Review Management
Collect and display customer reviews. The admin controls which reviews are shown publicly, building trust automatically.
